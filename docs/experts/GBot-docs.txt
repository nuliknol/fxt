  For optimization, yes, the built-in Strategy Tester is the obvious tool.
  But do not let it search arbitrary negative or huge values just because the
  code allows them. This code has almost no sanity bounds, so unconstrained
  optimization can produce nonsense and severe overfitting.

  Important
  If you run all of these exhaustively together, the combinations explode:

  - 11^6 * 14 * 13 * 19 * 29 * 20
  - roughly 17.5 trillion combinations

  That is not practical in MT4 Strategy Tester.

  What to do instead
  Use staged exhaustive search:

  1. Fix CP_W_*, optimize only:
      - W_ExtremeDeviation
      - W_ProfitGiveback
      - W_CandlePressure
      - HarvestThreshold
  2. Then fix those and optimize:
      - CP_W_Body
      - CP_W_Close
      - CP_W_Wick
      - CandlePressureDecay
  3. Then optimize:
      - DeviationK
      - WickCapMultiplier
      - ScoreClampMax
